# 徳島 ベビー用品セールチェッカー ver 2.7

GitHub → Vercel 配備用のNext.jsアプリです。

## V2.7のポイント

指定店舗ごとに公式チラシを最優先で取得し、取得できない場合はShufoo!等の指定店舗ページを利用します。画像/PDFの直接ダウンロードができないCanvas/JS型ビューアーでは、ページ全体ではなくチラシ表示領域だけをスクリーンショットしてOCRします。

最新性は2段階で確認します。

1. 公式/Shufoo!掲載ページに記載された売出期間・掲載日を抽出。
2. 実際のチラシ画像/PDF/スクリーンショットをOCRし、チラシ内の日付を抽出。

両者が整合した場合だけ「2段階一致」と表示します。片方が不明、矛盾、古い場合は最新と断定しません。

通常は1店舗120秒を目安に処理します。PDF、複数ページ、大容量、OCR文字量が多いケースでは自動的に最大300秒（5分）まで延長します。Vercel Function自体は `maxDuration: 300` です。

## 必要なVercel連携

- Neon Postgres: `DATABASE_URL`
- Vercel Blob: 接続済みPrivate Blob（OIDC / `BLOB_STORE_ID`）

既存のV2.6までのNeon/Blob設定はそのまま利用できます。

## デプロイ

GitHubリポジトリの中身をV2.7で上書きしてCommit/Pushしてください。VercelのGit連携が有効なら自動再デプロイされます。
