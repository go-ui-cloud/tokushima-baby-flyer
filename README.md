# 徳島 ベビー用品チラシチェッカー ver 2.19

GitHub → Vercel 配備用のNext.jsアプリです。指定された各社の公式URLのみを使い、チラシ/公式オンライン商品を取得・OCR・抽出します。Shufoo!検索は使用しません。

## V2.19の変更

- Private Vercel Blob の読み出しを `get(url, { access: 'private' })` に修正しました。
- 「チラシ」ボタンからPDF・PNG・JPEGをインライン表示できるよう、BlobのContent-Typeを保持して返します。
- Blob表示APIは `no-store` とし、古いブラウザキャッシュを表示しにくくしています。
- V2.16の前回表示維持、手動キャッシュ削除、UI改善、コストコ重複排除などはそのまま維持しています。


- 通常の更新では、前回の表示データや保存済みチラシを削除しません。
- 更新中も前回結果を表示したまま、新しい取得に成功した店舗から順番に差し替えます。
- 「キャッシュ削除」ボタンを追加。必要なときだけ、現在表示用DBキャッシュと保存済みチラシBlobを削除できます。CSV履歴は削除しません。
- 画面レイアウトを整理し、カテゴリ・店舗・進捗・最新性・処理時間などをアイコン付きで表示します。
- コストコオンラインの商品画像は小さめのサムネイルで表示します。
- コストコオンラインは、商品URL → 商品番号 → 正規化した商品名の順に重複判定し、同一商品を1件にまとめます。
- コストコオンラインだけ「抽出方法」は表示しません。

## コストコオンライン

下記2ページだけを対象にします。

- `https://www.costco.co.jp/Baby-Kids-Toys/Diapers-Wipes/c/cos_8.4`
- `https://www.costco.co.jp/Baby-Kids-Toys/Formula-Kids-Snacks/c/cos_8.5`

赤文字で「引き後」が確認できる商品だけを表示します。カテゴリによる除外は行いません。商品画像URLが取得できる場合は小さめの画像を表示します。

## OCR / 更新時間

- 通常は1店舗120秒。
- PDF・複数ページ・文字量が多い場合は最大300秒（5分）まで延長。
- 進捗は「店舗ページ確認中」「チラシを発見」「OCRを実行中」「日付確認中」「商品抽出中」などをリアルタイム表示。
- 進捗欄の「この店舗をスキップ」で現在店舗を飛ばせます。
- 最新性は、掲載元ページの日付 + チラシ画像/スクリーンショット内の日付の2段階で確認します。
- 日付不明や不一致を推測で最新扱いしません。

## 更新とキャッシュ

「最新情報に更新」では前回表示を維持します。店舗の新しい取得が成功した場合のみ、その店舗結果を差し替えます。失敗/手動スキップ時は前回結果が画面に残ります。

「キャッシュ削除」は明示的に押したときだけ実行されます。現在表示用DBキャッシュと `flyers/` Blobを削除しますが、更新履歴/CSV履歴は保持します。

## Vercel連携

- Neon Postgres: `DATABASE_URL`（V2.19では `POSTGRES_URL` / `DATABASE_URL_UNPOOLED` / `POSTGRES_URL_NON_POOLING` / `POSTGRES_PRISMA_URL` / `PG*` も自動認識）
- Vercel Blob: 接続済みPrivate Blob（OIDC / `BLOB_STORE_ID`）

既存のNeon/Blob設定をそのまま利用できます。
