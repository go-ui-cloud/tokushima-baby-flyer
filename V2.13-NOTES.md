# V2.13 changes

- Shufoo! fallback/search removed from every store. Only the user-specified official URLs are configured.
- Manual refresh first deletes old `flyers/` objects from Vercel Blob and clears current store/progress cache in Neon. Historical CSV rows remain.
- Vercel Blob proxy is now `no-store` to avoid stale browser caching.
- Browser cache is disabled and cleared before acquisition.
- Screenshots wait longer: after navigation/click the app waits for document completion, large images to finish loading (`complete`/`naturalWidth`), or a rendered canvas, then waits an additional moment before capture.
- The progress panel has a `この店舗をスキップ` button. It aborts the client request and also writes a server-side skip request so the running worker exits at the next progress checkpoint.
- Costco Online exposes two information-source buttons, one for each user-specified Costco URL.
- Costco Online scans only those two URLs and displays product tiles containing a red rendered `引き後` label. Category keyword filtering is not used for Costco extraction.
- Version label: ver 2.13.
